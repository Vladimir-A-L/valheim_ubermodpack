# Valheim Ubermodpack

Воспроизводимая сборка для кооперативного Valheim с дополнительными испытаниями поздней игры:
опасным Глубоким Севером, усиленными подземельями и редкими боссами.
Базовая сложность боя — «Стандарт», обычная добыча — ×3;
Forever Build 2 и сортировка поблизости входят в требования сборки.

Проект находится на этапе проверки обновлённого основного кандидата и автоматизации игровых сценариев.
Готового стабильного модпака пока нет. Точный статус проверок — в [сводке](docs/current-state.md).

В Git хранятся инструменты, сведения о версиях и собственная документация. Игру получает SteamCMD;
архивы модов загружаются из источников авторов. Локальные доступы, конфиги и результаты инвентаризации
хранятся вне публичных файлов. Сторонние моды имеют собственные лицензии.
