# Ограниченный замер радиального стенда

Исходник собирается отдельно для сравнения старых DLL и включается в DungeonDepthPrototype с 0.16.0.
Отдельный диагностический плагин не входит в пользовательскую поставку и её политику девяти модов.
Встроенный компонент выключен по умолчанию: `[Performance] Enabled = true` включает его только
в мире `ForestCryptQA`. Он не меняет ZDO, состав охраны, награды или сохранения.

- **F8:** 15 секунд прогрева и 30 секунд текущей сцены.
- **F9:** два таких интервала подряд: прежний ключ кэша и исправленный. Баланс в обоих одинаковый.
  Переключение очищает только кэш навигации. После завершения/выхода возвращается прежний режим.
- Во время пары сохранять место, повторять одинаковое движение камеры. Бой записывать отдельным F8.
  Сравнение старого и нового баланса требует отдельных свежих экземпляров с сопоставимым составом.

Файлы находятся в `BepInEx/config/RadialPerformanceProbe/manual-*.json` и могут содержать
приватные координаты. Не публиковать их целиком. Отчёт содержит UTC, интервалы кадров,
медиану/P95/P99, длинные кадры, процессорное время, GC, состав сцены и доступные FrameTiming.
Отсутствие GPU samples либо нулевые недоступные показатели не означает отсутствие нагрузки GPU.
На закреплённом headless Unity счётчик allocation возвращает заглушку: отчёт пишет `null`.
Полная перепись сцены и кэша вынесена за измеряемый интервал, внутри остаётся число существ.
Время методов включает вложенные вызовы; складывать строки нельзя. Инструментирование имеет накладные расходы.

Для отдельной диагностической DLL: `[Probe] Enabled = true`; запрос в том же каталоге:

```json
{"id":"unique-label","seconds":30,"warmup":15,"mode":"baseline"}
```

Сохранить как `request.json` атомарным переименованием. Один запрос одновременно;
`id` уникален, допустимы буквы ASCII, цифры, `-`, `_`. Запись длится 10–120 секунд,
прогрев 0–60 секунд. Это средство локализации, а не подтверждение комфортного клиентского FPS.
