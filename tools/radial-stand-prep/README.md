# Подготовка отдельного радиального стенда

Временный серверный инструмент `RadialStandPrep` 0.1.1 для закреплённой `DungeonDepthPrototype` 0.15.1.
Создаёт только служебные полы, таблички и порталы из штатных prefab; игровую DLL не пересобирает.
Перед ручной передачей DLL инструмента снимается. Объекты сохраняются штатными ZDO;
метка существующего хаба защищает их от разрушения опоры.

Работает только на сервере `ForestCryptQA`, при `[Preparation] Enabled = true` и без подключённых игроков.
Изоляцию конкретного мира обеспечивают отдельные каталоги, unit и порты
по [заданию](../../docs/tasks/radial-0151-r2-r3-r4-stand.md).
Не устанавливать в активную пользовательскую поставку.

Файловый API — приватный `BepInEx/config/RadialStandPrep/request.json`, один запрос за раз.
Каждый запрос содержит уникальный `id` и `action`; результат атомарно пишется в `<id>.json`.
Повторный ID запрещён, запросы с неизвестным результатом автоматически не повторять.

- `survey`: массив `points`, необязательный подъём луча `lift`; читает пол, нормаль, свободный корпус,
  готовность зоны и штатные переходы. Высокий луч может попасть в потолок; точку прибытия проверять отдельно.
- `hub`: `fixture`, `position`; создаёт площадку 22×22 м из 121 штатного каменного пола.
- `portal`: `fixture`, `position`, `yaw`, `tag`; создаёт один конец пары после проверки точки.
- `sign`: `fixture`, `position`, `yaw`, `text`; создаёт служебную табличку.
- `relocate`: те же координаты и `fixture`; переносит только собственный загруженный служебный портал.
- `fixtures`: читает объекты, сетевые пары порталов и физическую точку выхода.
- `actors`: читает HP, максимальное HP, щит, свойства и привязку помеченной охраны.

После размещения проверять фактический выход портала, путь к входу и обе стороны штатного перехода.
`area_ready` относится ко всем ZDO ближайших секторов; ожидать готовности после смены reference-точки.
Наличие пары и физическая проверка не подтверждают клиентский проход. Снятие инструмента проверять перезапуском.
Координаты, запросы, сохранения и журналы хранить в `.local/`.

```bash
.local/legacy-adaptation/tools/dotnet/dotnet build tools/radial-stand-prep -c Release -p:GameDir=/absolute/path/to/isolated/server
```

Артефакты `bin`/`obj` исключены из Git. Инструмент не выдаёт вещи, не меняет персонажей, двери или награды.
