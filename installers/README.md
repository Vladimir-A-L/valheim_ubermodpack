# Архивы установщиков

Этот каталог содержит локальные ZIP установщиков и их файлы `.zip.sha256`.
Архивы включают сторонние DLL и приватные настройки подключения, поэтому не попадают в Git.
В репозитории сохраняются только инструкции, версии и контрольные суммы в `manifests/`.

Текущий кандидат: **ForestCryptQA-Drug-0.10.0.zip** — собственная арена, бросок и возврат мини-босса.
Закрыть Valheim, распаковать архив в новую папку,
запустить `INSTALL.cmd` и выбрать `valheim.exe` прежней тестовой копии ForestCryptQA.
Установщик проверяет состав и создаёт резервную копию перед заменой файлов.
Сохраняется исправление установщика 0.9.2 ревизии 2: старые копии сверх лимита сохраняются
в `ForestCryptQA-private-backups\archive` без удаления, после проверки новой копии.
Обновление с 0.9.2 и восстановление исходной DLL проверены на Windows в отдельном временном каталоге.
[Ручные задания U1–U9](../configs/miniboss-arena/README.txt),
[проверки и ограничения](../docs/reports/2026-10-30-miniboss-arena-0100.md),
[состав и SHA256](../manifests/miniboss-arena-0100-20261030.lock.json).

Предыдущие выпуски сохраняются здесь для отката. Их установка требует соответствующего серверного checkpoint;
замена клиентского архива сама по себе не откатывает мир или серверного персонажа.
Для возврата с 0.10.0 сначала сохранить текущие файлы, затем восстановить `original` из backup
в папку закрытой игры и согласованный серверный checkpoint. Старый ZIP поверх новой DLL не устанавливать.
