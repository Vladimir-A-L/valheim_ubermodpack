# Обновление согласованного основного набора

Дата для пользователя: 28 октября 2026 года, Asia/Yekaterinburg.
Машинные протоколы, конфиги runtime, журналы и кадры хранятся в `.local/update-20261028`, время — UTC.

## Основание и настройки

Пользователь подтвердил длительную игровую сессию с перечисленными модами и разрешил их обновление.
Это пользовательские сведения о работоспособности; проверка новых версий записывается отдельно.
Предварительная приёмка разрешена при отсутствии предупреждений. Полная игровая приёмка не заявляется.

- Обычные ресурсы: штатное ×3, без изменений.
- EpicLoot: профиль `balanced`, `Global Drop Rate Modifier = 0.7`. Допустимый диапазон новой версии — 0–4.
  Этот коэффициент уменьшает относительную вероятность добычи EpicLoot; обычные ресурсы не меняются.
- Forever Build 2: Multiplier ×3 с опорой на землю; Bloodgill в Monstrum выключен.
- Согласованные параметры существующих рюкзаков и растений сохранены в `configs/core`.
- UsefulPaths исключён из нового client/server.
- TidyChests: `Radius = 15`, `ScanRadius = 15`, `ConfigPriority = true`, `LearnFromChests = false`.
  Изучение рецептов по сундукам выключено по отдельному ответу пользователя.
  Горячая панель исключена из складывания; прочие параметры нового мода — его defaults.

## Техническая проверка

- До установки проверены ресурсы Linux и Windows, отсутствие игры и свободные серверные порты.
  Тестовый сервер ограничен 5 ГиБ RAM и 200% CPU. Это ресурсы стенда, не оценка целевого онлайна.
- Перед запуском защищён проверенный клиентский backup. Предыдущая серверная поставка и состояние сохранены.
- TidyChests отдельно: BepInEx и один плагин, `1 loaded, 0 skipped, 0 failed`, готовность и штатное сохранение.
- Полная сборка: сервер `12 loaded, 0 skipped, 0 failed`, клиент `13 loaded, 0 skipped, 0 failed`.
  Основные DLL установленного кандидата сверены с lock; UsefulPaths отсутствует.
- Сервер принял EpicLoot 0,7 и параметры TidyChests 15 м без изучения рецептов.
  Проверены сохранённые параметры рюкзаков и PlantEverything после генерации новых конфигов.
- Сценарий подключения прошёл все пять переходов с OCR. Персонаж визуально подтверждён в Лугах,
  инвентарь открывается и закрывается, кнопки Stash и Restock доступны.
  Автоматический сценарий инвентаря остановился по `observation_expired` до отправки первого действия;
  это `inconclusive`, а не успешный прогон. Визуальные проверки выполнены по отдельным свежим кадрам.
- После штатного выхода клиента в его журнале не обнаружено исключений; сервер штатно сохранил мир.
  Проверены 109 файлов компактного checkpoint, затем мир из него загружен в отдельном каталоге и сохранён.
  Повторное подключение клиента к восстановленному checkpoint в этом прогоне не выполнялось.
- Пик учтённой серверной памяти в основном прогоне — около 2,83 ГиБ при одном клиенте.
  Это короткая проверка, не измерение предельного онлайна.
- Инструменты: 23 теста, compileall, shellcheck и `git diff --check`.
  Добавлены проверки сборки новой версии вне исходной инвентаризации и несоответствия зависимостей lock.

При первом запуске кандидат получил консольный default BepInEx из-за разделителей путей Windows в ZIP.
Ввод остановлен при неверном окне; клиент штатно закрыт, профиль журналирования восстановлен, затем перезапущен.
Захват теперь требует `UnityWndClass`, поэтому консоль того же процесса не считается игровым окном.
Отказ по просроченному наблюдению также сохранён; отказавшие действия не повторялись без нового кадра.
Один ручной клик при выходе попал вне пункта Quit; отсутствие перехода проверено новым кадром,
после чего цель уточнена. Доставка ввода сама по себе не записывалась как успешный игровой результат.

## Замечания

- Jotunn: три неоднозначных имени prefab (`Stone1_huge`, `caverock_pillar`, `highstone`) также видны на клиенте.
- На сервере Armory и Monstrum предупреждают об отсутствующих группах звукового микшера:
  17 и 263 предупреждения соответственно в основном прогоне.
  На клиенте после входа таких предупреждений нет; это не доказательство исправности всех звуков в игре.
- Jotunn сообщает о неподдерживаемых полях `Dictionary` при исправлении mock-ссылок.
- Unity headless сообщает об ошибках видеошейдеров и `AsyncResourceUpload`; такие сообщения есть
  также в отдельном запуске TidyChests и в прежней проверке чистого сервера.

Предварительная приёмка не выставлена: условие пользователя об отсутствии предупреждений не выполнено.
Журналы не фильтровались ради получения чистого результата. На клиенте после входа осталось по три
предупреждения Jotunn о неоднозначных именах и mock-ссылках, исключений не обнаружено.

## Итоговое размещение и восстановление

Обновлённый кандидат установлен в постоянный тестовый профиль: Windows `ValheimTest\current`,
Linux `.local/server-gameplay` и `.local/state-gameplay`. Ярлык и `.local/stand.env` используют прежние пути.
Клиент и сервер остановлены, временных задач визуального контроллера нет.

Предыдущий клиент сохранён в `ValheimTest\previous-20261028`, сервер —
в `.local/releases/core-before-20261028/server`. Предыдущие версии и хеши находятся в
[истории manifest](../../manifests/history/core-20261027.lock.json).
Согласованный checkpoint до обновления — `.local/backups/stand-20261028-checkpoint.tar.gz`;
его 30 файлов состояния сверены перед удалением дублирующего каталога.
Данные EpicLoot текущего мира совпали с прежними побайтно; данные других старых тестовых миров
остались в предыдущей поставке и её checkpoint.

Новый серверный checkpoint — `.local/backups/core-update-20261028-checkpoint.tar.gz`.
Он связан с клиентским backup записью `.local/update-20261028/final-checkpoint.json`.
Сверены 1076 файлов серверной поставки по локальному полному manifest и основные DLL всех 14 клиентских пакетов.
Согласованные значения клиентских конфигов совпали с исходным профилем после миграции.
Устаревшие ключи EpicLoot приведены к формату новой версии; открытие гнёзд теперь `Ctrl+E`.
Оставлены пять серверных архивов и пять клиентских, три клиентские точки защищены.

Для отката остановить процессы, вернуть предыдущие бинарники и согласованное состояние до обновления,
включая клиентское сохранение и внешние данные EpicLoot. Одной замены DLL недостаточно.
Полный игровой откат обновления и два одновременных клиента в этой сессии не проверялись.
