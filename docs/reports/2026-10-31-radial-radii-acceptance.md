# Согласованные радиусы и ревизия поставки r2

31 октября 2026 года, Asia/Yekaterinburg. Пользователь выбрал **2000/4500 м** и разрешил при отказе
геометрии ванильный склеп с записью причины. R2 отложена ответом «Проверю позже»; приёмка не объявлена.

В [конфигурации](../../configs/radial-dungeons/radial-dungeons.json) установлены `RadiiAccepted=true`,
`Fallback=vanilla`, `Revision=forest-radial-2`. Профили определяются по радиусу наружного входа:

| Радиус | Профиль |
| --- | --- |
| `r < 2000` | Стартовый |
| `2000 <= r < 4500` | Средний |
| `r >= 4500` | Дальний |

`Enabled=false` и `IntegratedEncounters=false` остаются до игровой приёмки кандидата.
Перед ванильным запасным вариантом удаляются частичные объекты; выбор и причина отказа сохраняются.
Уже посещённые склепы используют сохранённые планы и правила. Их перепланирование не выполняется.

Подготовлен [ForestCryptQA-Drug-0.15.1-r2.zip](../../installers/ForestCryptQA-Drug-0.15.1-r2.zip):
прежняя DLL 0.15.1, новая конфигурация и обновлённая инструкция. Из 11 файлов полезной нагрузки изменён
только `radial-dungeons.json`; код установщика прежний. Исходный ZIP 0.15.1 и его SHA256 сохранены.
[Manifest ревизии r2](../../manifests/radial-dungeons-0151-r2-20261031.lock.json).
SHA256 нового архива:
`6b7a0e53caf7aba0a9aa28adfd98ffac7b417c9318ea5454a80634e49e469443`.

Модель прошла 94 072 утверждения, включая точные границы 2000/4500 м, промежуточные 4000 м
и отрицательные наружные координаты. Проверены ZIP и SHA256 всех файлов полезной нагрузки.
Согласование параметров отделено в проверках от включения обычной генерации.

Нативные результаты, нагрузка и проверка Windows относятся к исходной поставке с пробными 2000/4000 м;
они не повторялись ради изменения конфигурации. Их условия и ограничения сохраняются в
[отчёте 0.15.1](2026-10-31-radial-0150.md). Проверенные девять контрольных входов остаются в тех же
профилях при новых границах. Для 2000/4500 м каталог трёх seed уже содержал 145–155 средних
локаций: по мирам 155, 145 и 154; пограничные случаи разобраны в исходном отчёте.

Активный сервер остаётся на 0.14.1; клиент и мир не менялись. Архив r2 предназначен для последующего
совместимого стенда. Остаются R2, затем R3/R4; U9 — после окончательной одиночной приёмки.
