# Текущее состояние

Обновлено 27 октября 2026 года. Этап: подготовка стенда и первый кандидат основных модов.
Это ещё не стабильный модпак и не готовая поставка для постоянного сервера.

## Что подготовлено

- Правила работы, игровой план, инструкции сборки, запуска, резервирования и переноса.
- Беспарольный SSH к тестовому Windows-клиенту и проверенный доступ к целевому Linux-хосту.
  Доступы хранятся вне Git; тестовый клиент пока остаётся чистым.
- Стенд разработки: Linux, 6 vCPU, около 7,8 ГиБ RAM. Установлены зависимости и SteamCMD.
  Целевая машина: 44 логических CPU, около 62,7 ГиБ RAM и 763 ГиБ свободного диска;
  это измерение доступных ресурсов, а не оценка игрового онлайна.
- Valheim dedicated server `l-1.0.20`, сетевой протокол 41, Steam build `25909431`.
  У клиента установлен Steam build `25909357`. [Идентичность сервера](../manifests/server-build.json).
- Из присланной инвентаризации выделены основные DLL 26 пакетов. Загружены 14 пакетов кандидата,
  их основные DLL совпали с пользовательскими SHA256/размерами. Архивы и зависимости закреплены
  в [lock](../manifests/core-candidate.lock.json).
- Серверный overlay содержит 13 пакетов; PlantEasily предназначен только для клиента.
  BepInEx — загрузчик, поэтому сервер регистрирует 12 плагинов, а не 13.
- Обычная добыча ×3: `-modifier resources most`, в сохранении подтверждено `resourcerate 300`.
- Собственные начальные конфиги отключают спавн Bloodgill в Monstrum и задают Forever Build 2
  режим Multiplier ×3. Остальные настройки пока сгенерированы модами и требуют балансировки.

## Проверки

- Чистый сервер: готовность, сохранение, повторная загрузка созданного мира.
- BepInEx и библиотеки: четыре плагина загружены, пропущенных и не загрузившихся нет;
  сервер достиг `Game server connected` и сохранил мир при штатной остановке.
- Начальный основной набор: 13 плагинов загружены, сервер готов; пик учтённой памяти около 3,10 ГиБ
  при лимите 4 ГиБ и 200% CPU, без игроков. После исключения клиентского PlantEasily — 12 плагинов.
- Проверены SHA256 DLL собранного серверного overlay, исключение клиентского мода и явные конфиги.
- Backup после остановки извлечён в отдельный каталог: мир прочитан, сервер достиг готовности,
  затем штатно сохранился. Тестовые процессы остановлены, игровые файлы стенда сохранены.
- `make check`: восемь тестов проверки архивов/зависимостей, Python compileall, shellcheck, diff check.

Результат восстановления backup и итоговый протокол — в [отчёте стенда](reports/2026-10-27-bootstrap.md).
Сырые журналы, состояния мира и архивы остаются в `.local/`; публичный отчёт содержит только сводку.

## Известные ограничения

- В чистом сервере и модифицированном профиле есть Unity-сообщения `AsyncResourceUpload failed`,
  ошибки headless-видеошейдеров и intro cinematic. Они не остановили запуск; их влияние на клиент ещё не проверено.
- Jotunn сообщает о неоднозначных именах нескольких prefab. Генерация сообщает о неполном размещении
  отдельных локаций, включая указатели босса Monstrum. Нужны игровые проверки доступности контента.
- У автора уже есть Monstrum 1.6.1 с исправлением спавнов после изменений Valheim.
  Здесь восстановлена и проверяется присланная версия 1.6.0; перед выпуском нужно отдельно сравнить 1.6.1.
  [Изменения автора](https://thunderstore.io/c/valheim/p/Therzie/Monstrum/changelog).
- [TidyChests 1.5.0](https://thunderstore.io/c/valheim/p/Muindor/TidyChests/) найден, но пока не включён.
  Потребуется закрепить архив, проверить сортировку в радиусе и выбрать настройки изучения рецептов.
- Spawn That, CLLC и OdinsHollow пока не установлены. Северные сценарии и подземелья не созданы.
- Нет подключения реального игрока, испытаний двух клиентов, проверки баланса или нагрузки.
  Пробный Steam A2S_INFO-запрос с Windows завершился таймаутом; причину нужно проверить при игровом входе.
- Docker-поставка и развёртывание на постоянной машине ещё не выполнены.
